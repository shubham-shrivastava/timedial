# Contributing

Thanks for your interest in improving TimeDial!

## Development setup
1) Clone the repo
2) Open `timedial.xcodeproj` in Xcode
3) Select the `timedial` scheme
4) Product → Run

## Guidelines
- Keep changes focused and small where possible.
- Prefer SwiftUI-only UI updates unless AppKit is required.
- Test menu bar behavior after changes.
- Use descriptive commit messages.

## Pull requests
1) Create a feature branch from `main`
2) Make your changes
3) Open a PR with a clear description and screenshots if UI-related

## Reporting issues
Please include:
- macOS version
- Steps to reproduce
- Expected vs actual behavior
- Screenshots or logs if relevant
