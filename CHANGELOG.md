# Changelog

All notable changes to this project will be documented in this file.

## 1.1.0 - 2026-02-15
- Increased timezone capacity to 6 total clocks (1 local + 5 additional).
- Added context menu actions for copy time, copy time + timezone, and remove clock.
- Added timezone favorites in picker and keyboard shortcuts (`Cmd+N`, `Cmd+,`, `Cmd+R`).
- Improved animation smoothness and reduced CPU usage when popover is closed.
- Fixed crashes related to timezone picker reopening and popover layout updates.

## 1.0.0 - 2026-02-01
- Initial public release.
- Menu bar–only macOS app with analog timezone clocks.
- Searchable timezone picker with GMT offsets.
- Persistent state (clocks, favorites, compact mode).
